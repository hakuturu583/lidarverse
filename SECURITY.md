# Security Policy

## Reporting a Vulnerability

Report suspected LidarVerse vulnerabilities or AI security concerns privately
using [NVIDIA's security reporting page](https://www.nvidia.com/en-us/security/report-vulnerability/)
or contact [NVIDIA PSIRT](mailto:psirt@nvidia.com).
**Keep vulnerability details out of public issues, pull requests, and discussions.**

For email reports, encrypt your message with
[NVIDIA's PGP key](https://www.nvidia.com/en-us/security/pgp-key/).
To help investigation, provide:

- The affected LidarVerse release or commit and, where relevant, checkpoint.
- A description of the issue and its security impact.
- Reproduction steps, environment details, and any available proof of concept.

## Security Resources

See [NVIDIA Product Security](https://www.nvidia.com/en-us/security/) for
security bulletins and the [PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/)
for disclosure procedures.
